# 🏰 FirstDefense

Unity 2D 기반 1인 개발 타워디펜스 게임입니다.

![Unity](https://img.shields.io/badge/Unity-2022.3-blue?logo=unity)
![Language](https://img.shields.io/badge/Language-C%23-green)
![Status](https://img.shields.io/badge/Status-In%20Development-yellow)

---

## 🎮 게임 개요
- 웨이브마다 몰려오는 적을 타워를 배치해 막는 2D 타워디펜스
- 직접 설계한 적 경로 탐색, 오브젝트 풀링, 웨이브 시스템 구현

---

## 🔧 기술 스택
- **Engine**: Unity 2022.3
- **Language**: C#
- **Tools**: GitHub, Visual Studio

---

## 🧩 구현 예정 기능
- [ ] 적 이동 경로 (웨이포인트 기반)
- [ ] 타워 배치 시스템
- [ ] 오브젝트 풀링
- [ ] 웨이브 시스템
- [ ] UI (체력, 골드, 웨이브)
